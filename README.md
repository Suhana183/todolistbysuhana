# 🌸 To do list – Modern Task Management App

To do list is a modern and responsive task management web application built using **HTML, CSS, and JavaScript**. It helps users organize daily tasks, set priorities, and manage productivity with a clean and attractive pink gradient interface.

---

## 🚀 Features

- 🌸 Beautiful Pink Gradient UI
- ✅ Welcome Screen
- 📋 Today's Tasks Dashboard
- ➕ Create New Tasks
- 📝 Task Description
- 📅 Date & Time Selection
- 🔥 Priority Levels (High, Medium, Low)
- ✔ Mark Tasks as Complete
- 🗑 Delete Tasks
- 💾 Local Storage Support
- 📱 Fully Responsive Design
- ⚡ Fast and Lightweight

The application automatically saves tasks in the browser using **Local Storage**.

This means:

- Refreshing the page will not delete your tasks.
- Closing and reopening the browser keeps your tasks.

## Troubleshooting

### CSS is not loading

- Ensure `style.css` is in the same folder as `index.html`.
- Verify the link tag:
  ```html
  <link rel="stylesheet" href="style.css">
  ```

### JavaScript is not working

- Ensure `script.js` is in the same folder.
- Verify:
  ```html
  <script src="script.js"></script>
  ```

### Get Started button doesn't work

- Check that `script.js` is loaded.
- Open the browser's Developer Tools (`F12`) and look for errors in the Console.

### Tasks disappear

- Make sure Local Storage is enabled in your browser.
- Don't use Incognito/Private mode if you want tasks to persist.
